# Music-genre-classification
Deep Learning-Based Music Genre Classification using GTZAN Dataset
## Project Overview

This project develops a deep learning-based system for automatic music genre classification using the GTZAN Music Genre Dataset.

The project compares four different neural network architectures:

1. Multilayer Perceptron (MLP)
2. 1D Convolutional Neural Network (CNN)
3. Long Short-Term Memory (LSTM)
4. Transformer

The models will be evaluated using a common experimental setup.

## Dataset

GTZAN Music Genre Dataset

- 10 music genres
- 1,000 audio tracks
- 100 tracks per genre

Genres:

- Blues
- Classical
- Country
- Disco
- Hip-Hop
- Jazz
- Metal
- Pop
- Reggae
- Rock

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix
